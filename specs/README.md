# Specs

This directory holds all specifications created via Spec Kit.

Each subdirectory follows the pattern: `NNN-feature-name/`

A spec directory typically contains:
- `requirements.md` — What to build and why (generated by `/specify`)
- `plan.md` — How to build it technically (generated by `/plan`)
- `tasks.md` — Actionable breakdown (generated by `/tasks`)

Use `speckit-to-issue create specs/NNN-feature/tasks.md --assign-copilot` to push tasks to GitHub.
